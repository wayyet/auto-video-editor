## 2. fonts.py 对比矩阵(计划任务 5.1)

| 行为点 | assembly_capabilities | video_edit_capabilities | 是否一致 |
|---|---|---|---|
| 覆盖目录 `override_dirs()` | `VE_FONT_DIRS` / `VIDEO_EDIT_FONT_DIRS`(os.pathsep 分隔) | 同 | ✅ |
| `font_dirs()` 搜索顺序 | override → `_LEGACY_DIRS` → 平台目录,去重,**不缓存** | 同(函数体逐字一致) | ✅ |
| `_LEGACY_DIRS` | `["/root/.fonts", "/usr/share/fonts"]` | 同(两套都保留 Linux 传统位置) | ✅ |
| `_find_named` | 先直接子级后递归 | 同 | ✅ |
| `_scan_by_hint` | 按后缀 + stem 提示扫描,bold 优先 | 同 | ✅ |
| `_find_cjk_font` 缓存 | `lru_cache(maxsize=8)`,键 `(weight, dirs_key)` | 同 | ✅ |
| fc-list 缓存 | `_fc_list_zh_families` / `_fc_list_zh_files` 各 `lru_cache(maxsize=1)`,`timeout=30` | 同 | ✅ |
| `family_of_file` / `ass_font_name` | 一致(仅注释语言不同) | 同 | ✅ |
| **fc-list 回退门**( `_find_cjk_font` 尾部) | `for path in _fc_list_zh_files(): return path` —— fontconfig 报什么就用什么 | `if covers_cjk(path) is not False: return path` —— fontTools 惰性读 cmap,验证"你好一"在字表内;`None`(无法判断,含未装 fontTools)放行,`False` 拒绝 | ❌ **真实差异 ①** |
| **ukai 候选族名**(`_FAMILY_BY_STEM`) | `("ukai", "AR PL UMai CN")` | `("ukai", "AR PL UKai CN")` | ❌ **真实差异 ②**(疑似历史笔误,但各自被测试/生产 trace 锁定) |

**差异 ① 的影响评估:**
- `video_edit` 的 `covers_cjk` 用 fontTools 惰性 import;主 venv **实际已装 fontTools 4.66.0**(assembly 模块 docstring"本仓库无此重型依赖"的说法已过时,仅作记录,本阶段不改代码)。
- 因此本机上门是**激活**的:fontconfig 误报(如 fc-match 回落 DejaVu Sans 渲染豆腐)时,video_edit 会拒绝该文件继续找,assembly 会直接接受。
- 未装 fontTools 的环境里 `covers_cjk` 恒返回 `None` → 门恒开 → 两套行为退化一致。
- 触达条件:常规路径(权重文件名 / 族名提示扫描)全部落空、走到 fc-list 回退时才生效——常规环境极少触达。

**差异 ② 的影响评估:**
- 仅当字体文件 stem 含 `ukai`(AR PL UKai 系列,常见于 Linux 发行版包)时,`family_of_file` 推断的族名不同,影响 `force_style=FontName=` 字段;Windows/生产 Windows 字体(Microsoft YaHei)不受影响。

## 4. 结论与后续原则(计划任务 5.3)

1. **维持"不合并"预设**:两处真实差异说明这组重复**已经承载了刻意的行为分化**(video_edit 保留"原始版"完整行为含覆盖校验门以匹配生产 trace;assembly 裁剪为精简版)。"为了减少重复文件而合并"会把分化面变成回归面。
2. 若未来确要合并:先在 Linux 批处理机补 `covers_cjk` 门与 ukai 族名两类场景的跨平台 golden 测试,再抽 `media_common/ffproc_core.py` + `media_common/fonts_core.py`,以策略参数暴露差异(`covers_cjk_gate: bool`、族名表),两套 Capability 保留轻量 wrapper。
3. `require_ffmpeg` 文案差异与 assembly 过时的"无 fontTools"docstring 记录在案,不在本阶段修改(阶段 5 无代码变更)。
4. 本审查不阻塞也不依赖阶段 6;阶段 6 文档同步将引用本结论。
