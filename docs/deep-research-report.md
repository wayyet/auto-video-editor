# AI视频剪辑自动化流程执行计划

整个视频剪辑流程分为多个阶段，每个阶段有明确的输入和输出，使用不同的自动化技能接口。具体步骤与对应技能如下： 

- **步骤1：清理缓存** – 调用 `/kuaishou-clean-cache` 技能（脚本化清理），删除系统盘中剪映（JianyingPro）等应用的旧缓存和临时文件。缓存文件默认存放在 `%LOCALAPPDATA%\JianyingPro\Cache\*` 目录；清理时务必保留日志、项目缓存等重要文件。  
- **步骤2-3：启动 OpenStoryline** – 调用 `/openstoryline-launcher` 技能启动 FireRed-OpenStoryline 的 MCP 服务和网页程序，并使用 VS Code 的 Microsoft Edge 开发者工具扩展打开 Web UI。OpenStoryline 基于模型上下文协议（MCP）架构运行，可精细控制视频编辑原语。  
- **步骤4：分镜输出** – 在 FireRed-OpenStoryline 中导入视频后，系统将进行“镜头级内容理解”并筛选高质量片段，自动生成故事板和脚本，用于后续视频剪辑流程。  
- **步骤5：导入剪映草稿** – 调用 `/openstoryline-to-jianying` 技能，将 OpenStoryline 生成的分镜和脚本以剪映项目草稿形式导出（*.cae），以便在剪映（CapCut 专业版）中继续编辑。  
- **步骤6：人工调整** – 暂停自动化流程，人工在剪映界面对视频片段顺序、时长进行审阅和微调。此阶段需要人工判断和干预。  
- **步骤7：时间轴适配** – 使用 `/jianying-speed-fit-35s` 技能，对每个分镜片段进行加速或减速处理，使总时长符合不超过35秒的要求。  
- **步骤8：添加字幕** – 使用 `/jianying-add-subtitles` 技能，根据视频旁白自动拆句并对齐生成字幕轨道。该技能可调用剪映原生字幕功能并添加动画效果。  
- **步骤9：添加转场特效** – 使用 `/jianying-inject-fx` 技能，在视频片段之间插入转场动画和视觉特效。  
- **步骤10：字幕动画** – 使用 `/jianying-inject-text-fx` 技能，为字幕文本添加花字样式和动画效果（如打字机等）。  
- **步骤11：字幕贴纸** – 使用 `/jianying-inject-tts-sticker` 技能，为字幕元素注入贴纸装饰。  
- **步骤12：人工添加BGM** – 流程暂停，由人工在剪映中选择并添加背景音乐（BGM）。此阶段需要创意判断，自动化暂不介入（未来可考虑内容自动匹配音乐）。  
- **步骤13：音量调整** – 在剪映中对视频和音频轨道的音量进行平衡调整，或使用相应技能脚本控制确保听感舒适。  
- **步骤14：制作封面** – 使用 `/jianying-make-cover` 技能，在剪映中设计并导出 9:16 竖屏封面。同时在本地使用 Python 脚本（如调用 Pillow 库）将视频画面或设计底图裁剪生成 16:9 和 4:3 的横版封面。  
- **步骤15：封面本地化** – 使用 `/jianying-cover-localize-en` 技能，不进入剪映环境，将中文版 9:16 封面图上的中文标题替换为英文文本。可使用 Python 的 Pillow 库在图像上绘制英文文字。  
- **步骤16：字幕翻译** – 使用 `/jianying-translate-subtitles` 技能，将剪映草稿中的中文字幕翻译为英文。该步骤可调用大语言模型或翻译引擎（如 GPT-4、DeepL 等）自动生成英文字幕轨道。  
- **步骤17：注入英文配音** – 使用 `/jianying-inject-english-tts` 技能，将英文字幕通过 AI 语音合成转为旁白（不添加贴纸）。Jianying Skill 支持调用微软神经语音引擎（例如 `edge-tts` 库）生成自然的英语配音。完成后导出最终视频。  

## 技术选型与选型理由

现代化的视频工作流常用 Python 作为“胶水”语言，实现对各工具的调用和协调。以下为各步骤的技术选型及理由：

- **缓存清理（步骤1）**：选用脚本化方法（PowerShell 或 Python），方便定时执行并记录日志。可用 `os`、`shutil` 或第三方库定期删除 `%LOCALAPPDATA%\JianyingPro\Cache` 等目录下的过期缓存。Python 的跨平台和易用性使其适合作为自动化清理工具，且支持日志和异常处理。  
- **OpenStoryline 部署（步骤2-4）**：采用 FireRed-OpenStoryline 官方工具（可在本地环境或容器中部署），因为其提供基于大模型的智能分镜和剧本生成功能。该系统支持细粒度的编辑原语控制，可通过命令行或 API 触发分镜输出。VS Code 中安装 Microsoft Edge Tools 扩展便于启动并调试其 Web 界面。  
- **草稿导入（步骤5）**：使用开源的 `jianying-editor-skill` 工具来将 OpenStoryline 输出内容导入剪映。这一方案通过 UI 自动化（如安装了 `uiautomation`、`Playwright` 等库）模拟剪映桌面操作，能批量生成项目草稿。该工具专为中文剪映专业版优化，覆盖了素材导入、自动配音、字幕生成等功能（见下述）。  
- **剪映自动编辑（步骤7-11）**：选用 `jianying-editor-skill` 的自动化能力，包括变速处理、自动加字幕、插入特效转场、字幕动画和贴纸等。此技能库支持剪映原生功能，并已验证可从导入素材到自动导出一气呵成。使用该现成解决方案可以大幅提升开发效率，避免重复造轮子。  
- **背景音乐（步骤12）**：此阶段目前依赖人工选择，自动化算法可作为辅助，如未来接入内容情绪分析后自动推荐配乐。暂不强求自动化，重点放在后续技术实现上。  
- **封面生成（步骤14-15）**：9:16 封面可直接使用剪映设计工具生成。横版封面建议在本地生成，使用 Python 的 Pillow 或 OpenCV 进行图像处理。Pillow 库允许在图像上绘制文字和形状，适合用于封面文字叠加和尺寸转换。将中文版封面本地化为英文，只需在底图上绘制英文标题，灵活可控。  
- **字幕翻译（步骤16）**：采用大语言模型或翻译 API（如 GPT-4、DeepL、微软翻译等）自动翻译字幕文本。这些引擎在多语言翻译任务上表现优异。翻译后仍需人工审核纠错，以确保专业术语和语义准确。  
- **AI 配音（步骤17）**：使用 TTS 服务合成英文旁白。常见方案包括微软 Edge TTS（集成在 Jianying Skill 中）、Amazon Polly、Google Cloud TTS 等。鉴于依赖库中已安装了 `edge-tts`，可优先选用微软神经语音，它拥有多种发音风格且易于集成。

## 自动化执行顺序及人工干预点

整个流程按照依赖关系和人工审核需求分为若干执行阶段：  

- **自动化阶段**：依次自动执行步骤1–5（缓存清理、启动 OpenStoryline、分镜生成、导入剪映草稿）以及步骤7–11（调整时长、自动加字幕、添加转场特效、字幕动画、贴纸等），无须人工操作即可完成视频基础构建。  
- **人工干预阶段**：步骤6（人工调整视频片段顺序/时长）和步骤12（人工添加背景音乐）为关键审核点。流程在这两点处暂停，待人工完成编辑后再继续后续自动化步骤。  
- **后续自动化**：人工审核完成后继续自动执行步骤13–17，包括音量调整、封面生成与本地化、字幕翻译和英文配音注入等，直至输出最终成片。在人工阶段介入并反馈后，系统可继续无缝自动执行剩余步骤。

## 错误处理与缓存/资源管理策略

为了确保流程稳健运行，需要做好错误处理、日志记录与资源监控：  

- **阶段成功检查**：为每个任务定义明确的输入、输出和成功标准（例如：分镜导出后检查文件完整性，字幕生成后检查轨道数量）。每步执行完毕后记录日志，如若失败，脚本应抛出错误或尝试重试，并通知运维人员介入。  
- **资源监控**：使用 `psutil` 等库监测 CPU、内存和磁盘使用情况（依赖清单中已包含 psutil）。如果发现剪映或 OpenStoryline 占用过高且无响应，可自动终止并重启进程，并记录事件。  
- **缓存定期清理**：定时执行步骤1的缓存清理脚本，防止系统盘空间不足。脚本应根据缓存存储路径删除旧文件，并参考示例避免删除 Logs 或项目缓存。  
- **日志与备份**：所有自动化步骤均应产生日志和输出摘要，方便审计和故障排查。关键项目文件和配置在执行前后应进行备份（遵循中的建议），以便在异常情况下恢复。  

## 时间表与交付物清单

流程实施可分阶段推进，示例计划如下：  

- **第1周**：环境准备与基础设施搭建。安装配置 FireRed-OpenStoryline 与剪映专业版工具，编写并测试缓存清理脚本和 OpenStoryline 启动脚本。交付物：环境搭建文档、缓存清理工具、OpenStoryline 启动脚本。  
- **第2周**：分镜输出与导入测试。导入测试视频到 OpenStoryline，输出并审验故事板；开发 `/openstoryline-to-jianying` 功能，在剪映中生成项目草稿。交付物：测试视频的故事板文件，剪映工程草稿文件。  
- **第3周**：自动剪辑功能开发。完成变速处理、自动加字幕、特效插入等脚本（如 `/jianying-speed-fit-35s`、`/jianying-add-subtitles`、`/jianying-inject-fx` 等），并进行批量测试。交付物：处理后的视频分镜片段样例、带字幕和特效的剪映项目。  
- **第4周**：封面设计与本地化。设计 9:16 竖屏封面并生成 16:9、4:3 横屏封面，中英文版本。实现 `/jianying-cover-localize-en` 脚本自动替换封面文本。交付物：封面图像（中英文、三种比例）。  
- **第5周**：多语言字幕与配音。完成字幕翻译和英文配音注入的自动化脚本（`/jianying-translate-subtitles`、`/jianying-inject-english-tts`），并测试效果。交付物：英文字幕文件、英语旁白音轨，以及最终合成的视频样片。  
- **持续运维**：流程搭建完成后，每周运行并根据反馈优化。包括定期清理缓存、监控日志、调整参数和完善翻译校验等。  

**交付物清单**（示例）：缓存清理工具、OpenStoryline 故事板文件、剪映草稿项目文件、短视频片段文件、带字幕和特效的视频工程、封面图像素材（中英文各尺寸）、英文字幕文件、英文配音音频及最终输出视频文件等。

**参考资料：** FireRed-OpenStoryline 文档、JianYing 编辑器 Skill 文档、自动化视频流程指南等。
