## 二、验收项(按顺序过)

### ① 英文草稿内容 —— 字幕 + 花字 + 转场 + 贴纸

跑完一条完整流程后:

- [ ] 英文草稿能在剪映里正常打开(不报草稿损坏)
- [ ] 有**英文字幕**:字幕轨 `track_name == "Subtitles_en"`
- [ ] 有**花字**:描边 / 入场动画已生效(这是 `node_10b`,排在关卡③ 之前)
- [ ] 有**转场**(来自 `node_09`)
- [ ] 有**贴纸**(来自 `node_11`)

> 关键对照:中文草稿里**不应**出现 `Subtitles_en` 轨道;英文草稿里**不应**出现 `Subtitles` 轨道。

### ② 关卡③ 路径 —— 人为制造一句超长英文

这是本轮 K3=B 决策的**核心验收**,必须实测:

- [ ] 人为把某句英文改到超长(触发 `layout_issues_detected = True`)
- [ ] 流程在关卡③ 挂起
- [ ] **在剪映里打开英文草稿 → 花字已经生效**(这正是"10b 排在③ 之前"的意义:
      人工校对时看到的就是最终效果,不用"改完再等一步")
- [ ] 在剪映里改一句英文,保存草稿
- [ ] resume 之后,`subtitle_en.srt` 里**包含这句修改**

### ③ 关卡② 路径 —— BGM 镜像(只做一次)

- [ ] 流程在关卡② 挂起 —— 注意:**整个流程关卡② 只挂起这一次**
- [ ] 在**中文草稿**里加一首 BGM
- [ ] resume 之后,打开**英文草稿** → 出现**同一首 BGM**
- [ ] 两份草稿的 BGM segment id 相同(镜像按整轨复制,不 remap)

### ④ 音量 —— 两份草稿都要有

- [ ] 中文草稿:主音轨音量 1.0、BGM 0.35、淡入 2s / 淡出 3s
- [ ] 英文草稿:BGM 轨的音量与淡入淡出已写入

> ⚠️ **已知边界(R2),不要误判为 bug**:`node_17` 目前只合成音频文件、**不写草稿**,
> 所以英文草稿**没有主音轨 `audio_main`**。英文侧只能调到关卡② 镜像过去的 BGM 轨;
> 英文主音轨音量本轮不生效,要等 node_17 落地写草稿后才会有。

### ⑤ 交付物齐全

- [ ] 三比例封面,中文 + 英文都有(各 3 张)
- [ ] `subtitle_en.srt` 存在且非空
- [ ] 两份草稿素材都在(中文主草稿 + 英文分支草稿)
- [ ] `join_before_delivery` 的 QA 无新增 issue(`state["join_qa_issues"]`)

## 三、已知失败表现对照(出问题先对号入座)

| 现象 | 大概率原因 |
|---|---|
| 英文草稿打开报损坏 / 空白 | 英文草稿根本没生成 —— 查 `state["draft_dir_en_branch"]` 是否有值;缺失时尾链会降级只处理中文并写 `error_log` |
| 英文草稿有字幕但没转场/贴纸 | 模板库缺失(转场 303 / 视频特效 462 / 文字入场 78 / 循环 52 / 出场 46 都是 VIP 资源);此时 `error_log` 会有 `node_09_inject_fx_no_template` |
| 关卡③ 打开草稿看不到花字 | 顺序被改回去了 —— 确认 `node_10b_inject_text_fx_en` 仍在 `node_checkpoint3_layout_review` 之前 |
| 关卡② 要选两次曲 | 有人新增了 09b/11b/12b/13b 之类的英文实例节点,破坏了"同一节点内处理两份草稿"的设计 |
| 英文草稿没有 BGM | 关卡② 镜像失败 —— 查 `error_log` 里的 `[node_12] BGM 镜像到英文草稿失败`;中文草稿不受影响 |
| resume 后报 `InvalidUpdateError` | 同一超步内有两个节点在写同一个无 reducer 的键 —— 只允许新增并行节点返回 delta |
| resume 后 SRT 变成空文件 | 说明 `node_08b` 没生效(英文草稿里没有字幕文本素材,关卡③ 无物可校对) |
