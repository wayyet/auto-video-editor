## 附录 B：参考清理命令（按需执行，非自动运行）

> 以下命令仅供参考，执行前请自行确认；本文档仅做分析，未执行任何删除。

```powershell
$root = "c:\Users\wayye\Downloads\媒体剪辑\kuaishou"
$fr   = "$root\FireRed-OpenStoryline"

# 1) 服务端缓存（最大头，删后首次运行会重建）
Remove-Item -Recurse -Force "$fr\.storyline\.server_cache"

# 2) 项目源码字节码缓存（不动虚拟环境内的）
Remove-Item -Recurse -Force "$root\__pycache__", "$fr\__pycache__"

# 3) Playwright 调试产物
Remove-Item -Recurse -Force "$root\.playwright-cli", "$fr\.playwright-cli"

# 4) 日志 / 备份 / 测试输出 / 报告
Remove-Item -Force "$fr\web.out.log","$fr\web.err.log","$fr\mcp.out.log","$fr\mcp.err.log","$fr\install_log.txt"
Remove-Item -Force "$fr\config.toml.bak.*","$fr\test_result.txt","$fr\test_tts_result.txt","$root\env_check_report.txt"

# 5) tmp 临时帧（保留 4 个模板 json）
Remove-Item -Recurse -Force "$root\tmp\cover","$root\tmp\cover_frames","$root\tmp\frames","$root\tmp\scenes"

# 6) macOS 垃圾文件
Get-ChildItem -Recurse -Force -File $root -Filter ".DS_Store" | Remove-Item -Force
```
