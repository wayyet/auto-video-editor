## 阶段1:抽离有向图布局算法(2026-11-13)

**提交:`feat(节点地图·阶段1): ...`**

新增 `web/static/workflow_layout.mjs`(纯布局模块,无 DOM/HTTP/SSE 依赖):

- `detectFeedbackEdges(nodes, edges, options)`:三色标记确定性 DFS(邻接顺序=节点注册序+edge id 序),从 START 起、按 schema 序扫剩余连通分量;自环计反馈边;
- `assignVerticalRanks(nodes, edges, feedbackEdgeIds, options)`:排版边集上 Kahn 拓扑分层,`rank(v)=max(rank(u)+1)`,START=0;不可达节点按连通分量独立局部分层;
- `orderGraphLayers(nodes, edges, rankByNode, options)`:注册序为初始序,上下交替 barycenter 4-8 轮,仅交叉数下降才接受,平局回退注册序;
- `computeLayeredGraphPositions(nodes, edges, measurements, options)`:编排上述步骤并按实测尺寸分配坐标(NODE_GAP_X=48 / NODE_GAP_Y=64 / PADDING_X=48 / Y=40),每层水平居中;不可达节点放主流程下方独立区带;反馈边 lane 按 edge id 稳定排序、左右分侧+序号偏移;
- `getLayoutCacheKey({workflowId, mode, schemaVersion, direction})` 与 `LAYOUT_ALGORITHM_VERSION = "tb_v1"`。

`web/static/workflow_monitor.mjs`:`mainLayoutKey()` 增加可选第 4 参 `direction`——`"tb"` 追加 `_tb_v1`,其余/缺省保持现格式(向后兼容,现有断言不破)。

新增 `web/tests/workflow_layout.test.mjs`(node --test,无 DOM),覆盖计划文档阶段1 的 12 组用例:单链、一对多、多对一、三路汇合、条件边保语义、自环、多节点环、QA/QC/交付组合回路、不可达独立区、异构宽高不重叠、同输入输出稳定、缓存 key 隔离。`tests/test_workflow_monitor_frontend.py` 增加第 3 个 pytest 包装用例。
