# 执行记录:剪映朗读音色 TTS 后端(TTS_BACKEND=jianying)2026-11-14

## 0. 背景与目标

任务 console-50cd4c6af941 终局失败(交付 QA fail-closed):`voiceover_zh=failed; voiceover_en=failed` —— FireRed TTS(:8010)本机从未部署,中英配音全灭,而创建表单智能默认按 `TTS_BACKEND=firered` 预勾了配音必需(根因链见记忆 gate3-en-qc-calibration-20261114)。

用户指令:**把程序里的 TTS 改成直接使用剪映里的「朗读」音色**(截图2「热门」列表),把配音写进剪映草稿。

## 1. 机制(探索定案)

- 剪映「朗读」面板背后是字节 **SAMI 云端 TTS**,可 WebSocket 直连:
  `wss://sami.bytedance.com/internal/api/v2/ws?device_id=<did>&iid=<iid>`,
  app_id=`3704`,appkey=`IZjhUeAYwP`,payload=`{text, speaker, audio_config{ogg_opus,24000,64000}}`,
  StartTask→FinishTask→收二进制帧至 TaskFinished/TaskFailed。
- 鉴权只需 device_id/iid(伪装剪映客户端 UA `JianyingPro/5.9.0.11632` = 本机便携版版本),无需登录凭据。
  参考实现:isYangs/jianying-editor-skill(MIT)`scripts/universal_tts.py`。
- 音色表 = isYangs `data/tts_speakers.csv`(163 条,与截图2「热门」列表一致);
  清亮男声=`zh_male_iclvop_xiaolinkepu`(截图1选中)、英语女王=`en_female_kat_clone2`(表内唯一英文音色)。
- SAMI 返回 ogg_opus → **ffmpeg 转 24kHz mono PCM WAV**:现有链路
  (`read_wav_duration_ms` / node_08 `_wav_usable` / node_13 / draft_integrity)全按 WAV 头判时长。
- 草稿写入**零改动**:node_08 `_write_zh_voiceover_track`(轨 `Voiceover_zh`,按组建时间区间铺段)+
  node_17 `_write_en_voiceover_track`(轨 `en_voiceover`)原样消费 WAV —— 这就是「音色进草稿」的落点。

⚠️「克隆音色」标签页(需登录+录声克隆)**不在本次范围**;本次实现的是与剪映朗读同引擎同音色的「热门」音色。

## 3. 关键实现细节

- **device_id 正则**:TTNet config 真实形态是 `device_id&#*1941114026465464`(数字前隔着字面 `*`,
  isYangs 的 `&#*(\d+)` 匹配不到)→ 放宽为 `&#[#\*]*(\d+)`;实测本机取到真值 `1941114026465464`。
  日志里无 `iid=`(近 3 个 log),iid 走兜底常量 `2314914062247833` —— SAMI 实测接受。
- **Windows 事件循环**:`asyncio.SelectorEventLoop(selectors.SelectSelector())` 每次会话新建
  (Proactor 规避,参照 scripts/resume_workflow.py 先例)。
- **音色回退**:未知音色名不杀配音 → 回落默认(中文链路清亮男声),`voice_requested` 留痕。
- **懒 import**:`jianying_tts ↔ tts_client` 双向均函数内懒 import,杜绝模块级单例解析期的循环初始化。

## 7. 风险与边界

- SAMI 是剪映内部接口(appkey 来自 MIT 参考实现):存在风控/限流可能。失败语义与现有降级一致
  (error_log + 交付 QA 拦截),不静默出坏音频;单客户端重试 2 次。
- 真正的「克隆音色」(登录后自定义声音)不支持 —— 需登录态与克隆流程,独立后续工作。
- FireRed 链路完整保留:`TTS_BACKEND=firered` 一键回滚(需本地 FireRed 服务)。
- 创建台音色下拉 UI 未做:默认清亮男声/英语女王 + env `TTS_VOICE_ZH`/`TTS_VOICE_EN` + LLM 按
  tts_ref.yaml jianying schema 推断(user_request 提到音色偏好时生效)。
