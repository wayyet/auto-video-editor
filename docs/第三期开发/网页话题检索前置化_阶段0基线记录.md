## 3. 契约冻结（实施前现状）

### 3.1 检索产物旧结构（`outputs/<thread_id>/storyline/search_web_topic.json`）

能力层返回 dict 由节点**原样透传落盘**（`node_search_web_topic.py:42-45`）：

```json
{
  "search_web_topic": [
    {"url": "https://example.com/", "title": "标题", "source": "duckduckgo_html"}
  ],
  "preview_urls": [],
  "error_code": null,
  "message": ""
}
```

- `error_code` 取值域（旧）：`null` / `"NO_RESULTS"` / `"UNKNOWN_PROVIDER"`；
- 网络异常被 `_ddg_html_search` 内部吞掉返回 `[]`，对外与无结果同样表现为 `NO_RESULTS`；
- item 仅 `url/title/source` 三键，无 snippet；
- 无 status / query_hash / searched_at。

### 3.2 status_log 标签（旧）

| 标签 | 触发 |
|---|---|
| `storyline_search_web_topic_done` | 能力层正常返回（**含** NO_RESULTS——空 query/无结果也打 done） |
| `storyline_search_web_topic_failed` | 节点内异常（error_log 手工拼 `[storyline:search_web_topic] TOOL_EXECUTION_FAILED: …`，未走 `append_error`） |

### 3.3 State 三键（`state.py`）

| 行 | 键 | 语义 |
|---|---|---|
| 286 | `storyline_understanding_artifact` | understand_clips 产物路径 |
| 288 | `storyline_groups_artifact` | group_clips 产物路径 |
| 298 | `storyline_web_topic_artifact` | search_web_topic 产物路径（条件） |

均为 `Annotated[Optional[str], _last_wins]`。
