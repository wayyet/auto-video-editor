## 0. 使用说明

- **两份文档怎么配合**：设计文档是分析与代码级细节的唯一来源（§2 重复清单、§3 逐项设计与 diff、附录 A/B/C/F 脚本与测试全文）；本文是执行顺序、任务卡与验收跟踪。执行某张任务卡时，按卡内"上游"字段打开设计文档对应小节照做。
- **任务卡字段**：上游（设计文档章节）、目标、涉及文件、做法（引用 + 要点）、验收（命令 + 预期）、提交信息、可跳过性。
- **红绿策略**：P3-0 的行为用例**先红后绿**（改代码前必须先看到失败）；其余任务按"改完 → 重点测试 → 标准验收（§4）→ 提交"推进。
- **验收口径**：`scripts/compare_junit.py` 按"用例名"逐个对照，不比总数——你仓库里历史上有过存量失败掩盖新增失败的问题（设计文档 §5.0）。
- **环境**：在仓库根执行；PowerShell 命令在 `pwsh` 窗口运行（仓库存量 `.ps1` 无 BOM 须 pwsh 运行，见 `docs/remove-chat-loop-20261104/regression.md` §7）；PostgreSQL 容器先启动（P0-3）。
