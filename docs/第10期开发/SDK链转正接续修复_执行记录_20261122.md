## 二、补漏定案(链任务交付的两个真实缺口)

### 缺口 1(最高危,每任务必错):音频轨名语义在编译稿丢失

SDK 编译把全部音频(配音+BGM+人工)压进单条 `audio_main` 轨,而四个消费者全部
**按轨名识别配音**(`Voiceover_zh`/`en_voiceover`),编译稿上全部失效:

| 消费者 | 后果 |
|---|---|
| node_13 `_audio_tracks_by_role`/`is_voiceover_track` | 配音被当 BGM:音量 0.35(NODE13_VOLUME_BGM)+ 2s/3s fade(应为 1.0 无 fade) |
| node_12 关卡② `_zh_bgm_missing`(`_bgm_segment_count`) | 配音被当 BGM 计数 → 无 BGM 任务不再挂起(关卡②语义失效) |
| node_12 v2 镜像 `mirror_bgm_to_en_draft` | 编译稿无 `Voiceover_zh` 轨名可排除 → resume 镜像时中文配音回灌英文草稿 |
| QA `check_no_zh_voiceover_in_en_draft` | 按轨名找中文配音轨 → 编译稿上恒假阴性 |

**修复(role 贯穿编译)**:
- `jianying_sdk/spec.py`:新增 `TRACK_VOICEOVER_ZH="Voiceover_zh"` / `TRACK_VOICEOVER_EN="en_voiceover"`
  常量(轨名单一来源);`AudioClipSpec.role` 扩展为 `bgm/voiceover/voiceover_zh/voiceover_en/manual`;
- `jianying_sdk/timeline_extractor.py`:音频 role 改按**源轨名**精确匹配优先
  (`Voiceover_zh`→voiceover_zh、`en_voiceover`→voiceover_en),node_05 sidecar id_map 仅作回退;
- `jianying_sdk/compiler.py`:编译按 role 分轨——配音各落回同名配音轨,其余进
  `audio_main`;`counts.tracks` 逐轨名计数(audio_main 只含 bgm/manual);
- `nodes/_dual_draft.py`:两轨名常量改从 `jianying_sdk.spec` 同源引用(禁止双处硬编码)。
- **下游零改动自动恢复**:node_12/13/QA 的轨名识别逻辑在编译稿上重新成立;
  QA bgm 计数、`check_audio_mirror` 同步恢复。

**已知边界(记录不修)**:node_05 sidecar 泛 `voiceover` role(轨名不匹配的罕见回退路径)
仍落 audio_main——生产上 node_08 重铺恒带 `Voiceover_zh` 轨名,此路径实际不可达。

### 缺口 2:QA text_animation 类在编译稿上恒 n/a

编译稿文本 material id 是 uuid、动画素材落 `materials.animations`(vendor
script_material),legacy 的"前缀 id + material_animations 绑定"双口径均失效——
该必需类检查实质下线。

**修复(spec sidecar 口径)**:`draft_ops/draft_integrity.py` 新增 `_load_compiled_spec`
(收敛 sidecar 读取,`_sdk_compiled_subtitle_count` 同步改用)与
`_text_animation_state_from_spec`;编译回执 ok(compiled/skipped_fingerprint)时:
- `kind=text_animation` 编译降级项逐条 issue(SEV_ERROR → 类别 failed,required 闸门生效);
- 动画计划/字幕计划计数进 `counts`(source=sdk_compile);
- spec 无字幕计划 → n/a;非编译稿(读取失败/编译失败)→ 回退 legacy 前缀 n/a 口径。

**与 legacy 的偏差(有意,记录)**:legacy 尾链对"我方字幕缺动画绑定"报 SEV_ERROR,
即"动画计划为 0 但字幕存在"会挂闸门;编译稿口径**不造此新失败**——零选取是 node_10
的非破坏设计路径(资源守卫未过时合法不写),真实资源级失败由编译降级项承载。
若未来要恢复强闸门,把 `planned_anim==0 and planned_subs>0` 分支加回即可(执行记录留痕)。
