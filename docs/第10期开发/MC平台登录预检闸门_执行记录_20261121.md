## 5. 重要发现:修正下午的「xhs pong 假阴性」误判

下午验证记录的「xhs pong 假阴性(风控抖动)」**判断有误**。真机冒烟取证链:

1. `https://www.xiaohongshu.com` 与 `edith.xiaohongshu.com` 普通 httpx GET 均 1.2-1.4s 通(HTTP 302/200)
2. selfinfo 端点裸 GET → HTTP 406(1.4s,IP 未被封)
3. MC venv 无浏览器 → 406(0.3s);与 Edge CDP 并存同循环 → 406(0.2-0.3s)
4. 真 `query_self`(带签名+Cookie)→ **0.5s 返回 -104 无权限访问**

结论:pong 失败不是假阴性,**xhs 会话在 14:01 爬取成功后即被平台收回**(今天 02:58 首败→14:00 成功→14:06 起持续失败的形态与记忆中 `console-654141c9890e` 的风控嫌疑一致)。当天下午 3 次 `ConnectTimeout`(15:0x)是独立的瞬时网络抖动,15:25 自愈——tri-state 设计在该场景下正确 fail-closed 而非误弹二维码,价值得到验证。
