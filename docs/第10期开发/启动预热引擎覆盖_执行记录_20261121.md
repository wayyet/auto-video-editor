## 一、根因(定案,勿重查)

执行 `.\start_production.ps1` 必然弹出可见浏览器依次打开 xhs/dy 主页。触发链:

```
start_production.ps1 Phase 2(原 :872,无条件)
  → scripts\run_workflow.py --thread-id video-001(预热线程,全图真跑)
    → storyline_group_clips → storyline_search_web_topic(graph.py:746,每轮必跑)
      → 缓存常态 miss(request_hash 含 LLM 输出派生的 query_hash)
        → MC 登录预检闸门(search_web_topic.py:1490-1520,默认 STORYLINE_WEB_TOPIC_MC_LOGIN_GATE=true)
          → 逐平台(xhs→dy)子进程 MediaCrawler\check_login.py
            → CDP 启动可见浏览器(base_config.py:73 CDP_HEADLESS=False)
              goto https://www.xiaohongshu.com / https://www.douyin.com
```

实机铁证:`outputs\video-001\storyline\search_web_topic.json`(mtime 2026-11-21 15:48:54,对应 15:44:45 启动)login_preflight verdict=pass、xhs LOGGED_IN 17031ms、dy LOGGED_IN 15921ms、headless=false。闸门过后真实检索(search_notes `--headless 0`)还会弹第三个可见窗停在 xhs 首页数分钟。

## 二、处置方案(用户拍板改法B)

**预热保留全链冒烟价值,仅预热那一次运行的网页话题引擎临时切回 `bing_html`**(纯 HTTP 抓取,不开浏览器、不触 MC 登录闸门)。创建台真实任务不受影响(仍默认 mediacrawler)。

### 作用域安全性论证

| 环节 | 时机 | 是否继承覆盖值 |
|---|---|---|
| 监控服务 uvicorn(Phase 0.6/0.7,:715-730 起) | 先于 Phase 2 设变量 | ❌ 继承不到 |
| 创建台真实任务(console_service 从服务进程 Popen 派生 run_workflow.py) | 服务启动之后任意时刻 | ❌ 服务环境无此值 |
| 预热 run_workflow.py 子进程 | Phase 2 设变量期间 | ✅ 唯一继承者 |

`STORYLINE_WEB_TOPIC_ENGINE` 在 config.py :86-97 于进程 import 期读取,bing_html 为历史默认引擎(回滚路径之一),纯 HTTP 抓取无浏览器。

### 改动点(5 处,均在 start_production.ps1)

1. **$envBackup 名单**加 `'STORYLINE_WEB_TOPIC_ENGINE'`(:359 附近)——finally(:1001-1010)对旧值为 null 的变量执行 Remove,异常中断(exit 关键字路径)兜底还原,防污染调用方会话。
2. **Phase 2 执行前**设 `$env:STORYLINE_WEB_TOPIC_ENGINE = 'bing_html'` + Write-Phase 说明行(:871 附近,LLM 后端确定之后、`$pyOutput = @()` 之前)。
3. **Phase 2 执行后立即删**:`Remove-Item Env:STORYLINE_WEB_TOPIC_ENGINE -ErrorAction SilentlyContinue`(:884 `$pyExit = $LASTEXITCODE` 之后、exit 27 分支之前)——成功/失败/exit 27 全路径都先删除。
4. **头部注释**同步:Phase 清单(:16)+ 关键设计段(:32 后)。
5. **-WhatIf 计划打印**补一行覆盖提示(:288 附近)。
