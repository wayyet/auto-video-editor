## 2. P1:安全写入与回滚缺口修复

### 2.1 P1-01 双写异常自动回滚(`draft_ops/atomic_writer.py`)

- 旧缺口:`safe_write_draft` 的快照回退只覆盖 "verifier 返回 False";`atomic_write_draft_pair` 抛异常(如 content 写成功、info 的 `os.replace` 失败)直接穿出,草稿停留在 content 新/info 旧的半成品状态;回退本身抛 `FileNotFoundError` 时还会吞掉原始异常。
- 修复:双写与校验纳入同一 `try` 块;任一异常 → `_restore_or_fail` 恢复快照 → 抛复合 `RuntimeError`(原始异常 + 快照位置);**回退也失败** → 同时携带原始异常、恢复异常、快照位置与「草稿可能处于不一致状态,请人工从快照恢复」提示。
- **行为契约变更**:pair 写失败不再裸透传 OSError —— 原 `test_safe_write_draft_propagates_oserror` 已按新契约改写为 `test_safe_write_draft_write_exception_restores_and_raises_composite`(断言两文件恢复原字节 + 异常含原始错误与恢复结果)。

### 2.2 P1-02 三态进程检测(`draft_ops/safe_write_guard.py`)

- 旧缺口:检测命令失败/超时/工具缺失统一返回 `[]` → `False` =「未运行」,fail-open。
- 修复:新增 `probe_jianying_state()` 返回 `PROC_RUNNING / PROC_NOT_RUNNING / PROC_UNKNOWN`;默认查询函数失败时返回 `None`(=UNKNOWN)。
- `check_jianying_not_running()` 保留旧布尔口径(True=在跑,**语义不反转**),内部改由三态探测实现(unknown 折叠 False)—— 5 处既有调用方(draft_lock / draft_publisher / atomic_writer / 脚本 / 单测)行为零变化。
- `atomic_writer._default_proc_checker`:unknown → **raise RuntimeError**(fail-closed);注入式 proc_checker 布尔契约不变。
- 措辞:该机制是「进程状态门禁」,无系统级互斥;检查通过后剪映仍可能被启动,不声称排他锁。

### 2.3 P1-03/P1-04 布局自校验纳入事务(`scripts/fix_draft_subtitle_wrap.py`)

- 旧缺口:`_verify_dir` 在 `safe_write_draft` 成功**之后**调用,违规仅 `return 2`,已写入内容不回滚;且旧版自校验用草稿画布、折行用参数画布,口径可能不一致;`if not result.get("ok")` 分支为死代码(失败一律 raise)。
- 修复:组合校验器 `_make_tx_verifier(canvas)`(`verify_draft_loadable` + 行宽校验)传入 `safe_write_draft` 的 `verifier` 参数 → 布局违规在**提交前**触发整目录快照回滚;折行与自校验统一画布口径(`--canvas-width` > 草稿 `canvas_config.width` > `config.CANVAS_WIDTH`);死代码改 try/except 受控路径。
- **附加修复(用户批准)**:快照 GC —— `safe_write_draft` 成功提交后 `cleanup_old_snapshots(draft_dir, keep=SNAPSHOT_KEEP=3)`。此前 `cleanup_old_snapshots` 全仓无生产调用方,每次节点写入的整目录快照(含音视频素材)无限累积;失败回退永远取最新快照,清理最旧的不影响回滚路径。

### 2.4 P1-05 脚本专项测试(新增 `tests/unit/test_fix_draft_subtitle_wrap.py`,21 用例)

- 按路径 importlib 加载脚本模块(scripts/ 非包);tmp_path 假草稿 + 依赖注入/monkeypatch,不触碰真实用户草稿;autouse fixture 把脚本进程探测桩为 not_running(真实机器剪映开着也不抖动)。
- 覆盖:dry-run 不写盘 / apply 折行+range 重置 / 幂等(第二次 changed=0)/ 已有 `\n` 永不合并 / 六类素材分类计数(wrapped/empty/unchanged/unsupported_format/multi_style/non_dict)/ 空文本坏 JSON 安全跳过 / 多 style 不动 / preflight 缺目录整体拒绝(第一目录不得提前写入)/ 双目录独立事务汇总(1 落盘 1 回滚 exit 2)/ 进程 running+unknown 拒绝 / dry-run 不过进程门禁 / 写异常回滚(真实快照恢复原字节)/ 布局违规回滚 exit 2 / tx verifier 磁盘校验 / `--canvas-width` 0/负数 argparse 拒绝 / 显式画布改变折行 / 折行与自校验口径统一 / CPS 告警接线与零误报。

### 2.5 P1-06 多目录预检与独立事务语义

- 执行四步化(设计审查 §5.3):**Preflight**(全部目录存在性/JSON/顶层 dict → `--apply` 三态进程门禁,任一失败整体拒绝、不开始写入)→ **Plan**(内存生成计划,分类计数+布局告警)→ **Apply**(每草稿独立事务)→ **Verify**(事务内完成)。
- 中途失败不中断后续目录;结尾汇总「N 落盘, M 回滚, K 失败」+ 每目录状态行。
- 退出码:0 成功(含 dry-run);1 前置条件失败或写入失败;2 布局自校验失败(**已回滚**)。
