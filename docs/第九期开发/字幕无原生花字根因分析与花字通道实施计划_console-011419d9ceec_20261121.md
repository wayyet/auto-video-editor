**字幕没有花字,不是「效果丢失」,而是流水线从来没有原生花字通道。**

这是 2026-11-18 已定案的「当前未实现」能力(当时审查计划只交付了 P0 审计可观测 + P5 导出计数,池化接入 P2-P6 从未实施),不是本次任务的运行故障。2026-11-21 在最新 HEAD `edec4b0` 重新核实,四层缺失(资源池 / 写入代码 / 素材构造器 / vendor 元数据)全部仍然成立。

用户已拍板:**立项实施花字通道**,并确认两项产品决策:
1. `TEXT_FLOWER_ENABLED` **默认开启**(新建任务 zh/en 字幕自动挂花字;池无可用条目时 fail-closed 降级不写,不会产出坏草稿);
2. 应用范围 = **全部正文字幕**(`text-zh-N` / `text-en-N`,开场标题不挂)。
