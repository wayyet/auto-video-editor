## 3. 与审查文档的偏差(2 项,均已记录理由)

1. **ID 策略:** 审查阶段 1 要求「隔离草稿 GUI 验证 `text-flower-*` 前缀 ID 通过前不写正式草稿」。实施直接采用 **UUIDv5(固定命名空间派生)** —— 与 Golden Sample 的 UUID **同形**,从根上消除前缀 ID 兼容性风险,无需 GUI 门禁即可安全落地;我方素材识别改用私有标记键(对齐 `materials.texts` 私有字段先例)。命名空间串 `auto-video-editor/text-flower/20261121` 一经发布不得再改(改动=历史我方花字 id 失配,清理退化为少清理,不影响渲染)。
2. **收割工具延后:** 审查阶段 8 明确为可选独立排期;本轮不实现 `scripts/harvest_text_flower.py`,池扩充(更多 GUI 实证条目)留后续。

## 4. 金丝雀验收清单(操作员,顺序执行)

前置:重启 auto-video-editor 服务(env 生效);关闭剪映后再复跑全量(本轮回归时剪映未运行)。

1. **新建短测试任务**跑流水线(用隔离/测试素材,不动正式草稿);
2. 检查 zh/en 草稿 `draft_content.json`:`materials.effects` 出现 2 类条目——`type=text_effect`、`category_id=panel-text-flower`、`name=互动立体`、`path` 指向本机 `Cache/artistEffect/7407340226189757733/c093f229a5b9529beab4d27c00bc0c4f`;正文每条字幕的 `extra_material_refs` 含对应花字 id(UUIDv5 形态);开场标题/人工素材无花字;
3. 检查 `.autovideo_draft_mutations.jsonl` node_10 记录:`changed_counts.materials.effects` 变化 + `flower_fingerprint` 双侧非空;
4. status_log(事件流)出现 `node_10_text_flower_selected:互动立体@7407340226189757733(pool=1,usable=1,…,mode=auto)`;
5. **剪映打开草稿**:正文字幕显示「互动立体」花字效果(VIP 资源;确认当前账号订阅状态下可正常预览——资源 `is_vip=true` ≠ 账号已授权,审查 R-11);
6. **保存、关闭、重开**:花字仍显示;观察 GUI 是否复制条目/refs(重复属观察项,QA 对同 ID 同内容重复报 warning 不阻断);
7. 检查人工在剪映 UI 加的花字/文本完全不受流水线重跑影响;
8. FFmpeg 导出验证:报告出现「N 个原生花字(绑定 M 条字幕)未渲染进 MP4(剪映客户端内可见)」;不以 FFmpeg 成片作为花字通过依据;
9. **对照回归**:`TEXT_FLOWER_ENABLED=0` 重启后重跑同任务 → 草稿**不新增**花字、已有花字保留(关闭≠清理)、入场动画行为与主分支一致;
10. 验收通过后:新任务默认启用(缺省 true);**不自动回写历史草稿**。
